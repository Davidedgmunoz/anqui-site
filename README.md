# Anqui site

Static public pages for Anqui (privacy policy, support, credits), in Spanish (`/`) and English (`/en/`).
Plain HTML and one CSS file: no build step, no JavaScript, no external fonts or trackers.

Publish with GitHub Pages from the root of the default branch. Links are relative, so it works under a project path.

The contact address lives in every `support` and `privacy` page.
Once the app is live, replace the `#` App Store link in both home pages (see `TODO App Store link`).

The privacy page URL for App Store Connect is `<site>/privacy/` (Spanish) or `<site>/en/privacy/`.
Update the privacy policy before shipping any change that collects data (e.g. analytics).
